# Diagramas exportados de Excalidraw

En esta carpeta se guardan los diagramas creados a partir del código Mermaid de [`../diagramas.md`](../diagramas.md).

Por cada diagrama se guardan dos archivos con el mismo nombre:

| Extensión | Para qué sirve |
|---|---|
| `.excalidraw` | Archivo editable: se abre de nuevo en [excalidraw.com](https://excalidraw.com) arrastrándolo a la página. |
| `.png` o `.svg` | Imagen para mostrar en el README, los documentos y las diapositivas. |
